# Sube a B2 · Eduardo Stein

Vocabulario de inglés nivel B2. Palabra a la izquierda, definición a la derecha.
Los estudiantes solo leen; el profesor inicia sesión para agregar y borrar.

- `index.html` — la página
- `config.js` — configuración pública de Firebase
- `firestore.rules` — reglas de seguridad (solo el profesor escribe)

Stack: HTML estático · Firebase (Firestore + Authentication) · Vercel · GitHub.
